# Tamp Mail

Tamp Mail is a modern, privacy-focused temporary email service. It allows users to generate disposable email addresses to protect their primary inbox from spam and maintain online anonymity.

## Features

- **Instant Email Generation**: Create a random email address with one click using the Mail.tm API.
- **Multi-Mailbox Support**: Manage multiple temporary mailboxes simultaneously.
- **Real-time Polling**: Automatically refreshes every 10 seconds to check for new messages.
- **Bilingual Support**: Fully localized in English and Hindi.
- **Modern UI**: Responsive design with a dark theme, glassmorphism, and smooth animations.
- **Privacy First**: Emails are rendered in a sandboxed environment to prevent XSS and tracking.
- **PWA Ready**: Can be installed on mobile and desktop for a native-like experience.
- **QR Code & Sharing**: Easily share your temporary address via QR code or system sharing.

## Tech Stack

- HTML5 / CSS3 (Custom variables, Glassmorphism)
- Vanilla JavaScript (SPA architecture)
- Mail.tm API Integration
- Service Workers (Offline support & PWA)

## Usage

Simply open `index.html` in a web browser or host it on any static web server.
